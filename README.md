# Ninja Strike

A high-energy Local Co-Op action game.

## 🚀 How to Run (Windows)

The game has been built for Windows 11. You can find the executable here:
`Builds\Windows\NinjaStrike.exe`

## 🛠️ Development & Building

### 1. Open in Unity
You can quickly open the project in the Unity Editor by running:
- `OpenProject.bat` (Double-click this file in the project root)

### 2. Build for Windows 11
There are two ways to build the standalone Windows version:

**Option A: Inside Unity Editor**
- Go to the top menu: **Build > Build for Windows**.
- This will generate a fresh build in `Builds\Windows\`.

**Option B: PowerShell Script**
- Run `.\build_win.ps1` in PowerShell.
